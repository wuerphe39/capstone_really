PetMind 동작 애니메이션

반려견 소리를 기록하고, 보호자가 확인하고, 과거 기록으로 설명하는 흐름을 8단계로 보여줍니다. 처음이라면 ▶ 재생을 누르고 아래 설명을 따라가 보세요.

범례: 실선 상자는 구현·검증한 부분, 점선 상자는 가상 실행이거나 실장비 미검증인 부분입니다. 그림은 흐름을 단순화했습니다. 수집 프로그램·보호자 화면·가상 장치는 모두 서버 API(FastAPI)를 거쳐 DB와 YAMNet 서비스를 씁니다. 초록 점은 데이터·명령이 이동하는 모습입니다. 키보드 ← → 로 단계를 넘기고 Space로 재생/정지합니다.

용어 설명
짖음 후보
모델이 '개 짖음 소리일 수 있다'고 본 5초 구간입니다. 실제 짖음 횟수나 감정을 뜻하지 않습니다.
YAMNet
구글이 미리 학습해 둔 소리 분류 모델입니다. 이 시스템에서는 PC에서 로컬로 실행해 5초 소리에서 'Bark(개 짖음)' 점수를 읽어 짖음 후보를 찾습니다. 점수는 확률이나 정확도가 아닙니다.
RAG · MCP
질문과 관련된 과거 기록을 먼저 찾아 AI에게 근거로 건네는 방식입니다. MCP는 그 검색 도구를 부르는 표준 방법입니다.
클라우드 LLM (Gemini)
인터넷의 외부 서비스로 동작하는 생성형 AI입니다. API 키가 없거나 호출이 실패하면 PC의 규칙 기반 제공자가 대신 설명합니다.
SQLite
서버 PC 안의 파일 하나로 동작하는 작은 데이터베이스입니다.
