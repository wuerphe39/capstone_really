# YAMNet Bark 감지기 — ESC-50 전체 평가 (2026-10-23)

운영 감지기(YAMNet `Bark` 직접 점수, 5초 구간, **임계값 0.05**)를 ESC-50 2,000개 클립 전체에 그대로 적용했다. 개 짖음(`dog`) 40개를 양성, 나머지 49개 범주 1,960개를 음성으로 두었다. 요약은 [docs/evidence/yamnet_esc50_full.json](evidence/yamnet_esc50_full.json), 재현은 아래 명령이다.

```powershell
py -3.12 -m petmind.yamnet_service.app --port 8030        # 분석 서비스(별도 터미널)
.\.venv\Scripts\python.exe -m scripts.prepare_esc50        # 1회, 약 0.9GB, Git 제외
.\.venv\Scripts\python.exe -m scripts.evaluate_yamnet_esc50
```

## 왜 이 평가가 이전보다 독립적인가

- ESC-50은 **Freesound** 기반이고, YAMNet은 **AudioSet**(YouTube)으로 사전학습했다. 출처가 달라 AudioSet eval보다 겹침 가능성이 낮다. 다만 겹침이 없다고 보장하지는 못한다.
- 이 평가에서는 **아무것도 학습하거나 고르지 않았다.** 임계값 0.05는 이전에 정한 운영값이며 이 결과를 보고 바꾸지 않는다(아래 임계값 표는 참고용).
- 이전 평가([파트 47](47_AudioSet_시간구간_짖음_평가.md))는 53개 영상·106개 창이었다. 이번에는 음성 클립 2,000개로 오탐 범주를 훨씬 넓게 본다.

## 결과 (임계값 0.05)

| | 값 | 95% 신뢰구간 |
|---|---:|---:|
| 개 짖음 감지 | **40 / 40** (재현율 1.00) | 0.91 ~ 1.00 |
| 음성 클립 오탐 | **34 / 1,960** (1.7%) | 1.2% ~ 2.4% |
| 정밀도 / F1 | 0.54 / 0.70 | |

- 정밀도와 F1은 이 자료의 비율(양성 40 : 음성 1,960)에 좌우되는 값이다. 가정에서의 정밀도가 아니므로 재현율·오탐률을 본다.
- 개 클립의 점수 분포: 중앙값 0.78, 하위 10% 경계 0.45. 40개 모두 0.05를 넘었다.

### 오탐이 난 곳

| 구분 | 오탐 / 클립 | 범주별 |
|---|---:|---|
| 다른 동물 소리 | **24 / 360** (6.7%) | 수탉 6, 돼지 4, 고양이 4, 개구리 3, 소 3, 닭 3, 까마귀 1 (곤충·양 0) |
| 가정에서 날 법한 소음 29종 | **10 / 1,160** (0.9%) | 문 삐걱 3, 재채기 2, 변기 물 내림·웃음·아기 울음·숨소리·물 마시기 각 1 |
| 그 밖의 범주(비·바람·엔진·파도·불꽃 등) | 0 | |

사람과 가전 소리의 오탐은 적지만, **다른 동물 소리**(TV 속 동물, 밖의 닭·고양이 울음)는 짖음 후보로 오인될 수 있다. 서비스는 점수를 "짖음 후보"로만 표시하고 보호자가 원본을 확인하게 하므로 설계와 맞지만, 시연에서 다른 동물 소리를 틀면 안 된다.

## 해석과 한계

- **재현율 1.00은 낙관적이다.** ESC-50의 개 클립은 짖음이 또렷한 5초 전경 소리다. 이전 AudioSet 구간 평가는 짧고 잡음이 낀 짖음에서 5초 창 재현율 **0.737**(1초 미만 짖음 23창 중 12창 놓침)이었다. 실제 재현율은 두 값 사이, 조건에 따라 더 아래일 수 있다.
- 오탐률 1.7%는 ESC-50의 음성 클립이 모두 **뚜렷한 소리 사건**이라는 점에서 보수적이다. 평소 조용한 방에서는 이보다 낮을 것으로 보이며, 실제 방에서 측정하지는 않았다([LIVE_BARK_TEST.md](LIVE_BARK_TEST.md)의 소리 없는 구간 23개는 모두 0.0004 이하).
- 양성이 40개라 재현율의 신뢰구간 하한이 0.91이다.
- 이 평가는 **TV·말소리·초인종·진짜 짧은 짖음**을 포함하지 않는다. 방문 상황과 TV 소리는 별도 자료가 필요하다.
- **실제 사용자의 강아지는 평가하지 않았다.** 시연은 사용자 강아지로 찍을 예정이므로 촬영 전 예행연습이 필요하다.

## 결론

운영 임계값 0.05는 개 짖음이 또렷한 경우 놓치지 않고(40/40) 사람·가전 소음 오탐도 1% 안팎으로 낮은 "후보 거름망"으로 쓸 만하다. 약점은 (1) 짧고 약한 짖음의 놓침, (2) 다른 동물 소리의 오탐이다. 두 가지 모두 보호자 원본 확인 단계가 전제다.
