# 실제 소리 감지 시험 — 2026-10-23

노트북 스피커로 개 짖음 소리를 틀고, **같은 노트북의 내장 마이크(마이크 배열)와 웹캠**으로 자동 관찰 외출을 수집해 "마이크 입력 → 5초 구간 분석(YAMNet Bark) → 사건 영상 저장 → 화면 표시용 기록"까지 한 번에 확인했다. 재현은 `python -m scripts.live_bark_check --play` (소리가 크게 난다).

이 시험은 **기능 확인**이다. 소리는 공개 음원(ESC-50) 4개를 최대 음량으로 키워 스피커로 재생한 것이며 실제 반려견이 방에서 짖은 것이 아니다. 표본이 몇 개뿐이라 정확도·재현율 평가가 아니다.

## 준비에서 알게 된 점

| 상태 | 마이크 입력 | 결과 |
|---|---|---|
| 마이크 배열 "오디오 개선 사항" 켬 | 배경 −62 ~ −75 dBFS. 스피커로 튼 개 짖음·1 kHz 삐 소리가 오히려 더 **작게** 녹음됨(−83 dBFS) | 에코 제거가 노트북 자신의 스피커 소리를 마이크 신호에서 지우는 것으로 추정(원인을 따로 분리해 확인하지는 않음) |
| 개선 사항 끔 | 배경 약 −28 dBFS(잡음 바닥이 높음). 1 kHz 삐 소리는 −2 dBFS로 선명히 들어옴 | 스피커→마이크 경로 정상. 음량이 작은 파일은 잡음에 묻혀 최대 음량으로 키워 틀어야 함 |

- 스피커로 되돌려 녹음한 소리의 점수는 원본보다 낮다(원본 0.84 → 되녹음 0.31~0.78).
- 헤드셋이 기본 출력이면 소리가 마이크로 돌아오지 않는다.

## 결과 (임계값 0.05, 5초 구간)

| 소리(원본 YAMNet 점수) | 시험 1 (4개) | 시험 2 (2개) |
|---|---|---|
| dog_A 5-208030 (0.843) | **0.775** 감지 | **0.691** 감지 |
| dog_B 5-203128 (0.842) | **0.507** 감지 | **0.311** 감지 |
| dog_C 1-100032 (0.299, 원본도 약한 표본) | 0.003 **놓침** | — |
| rain 5-181766 (0.0) | 0.004 오탐 없음 | — |
| 소리를 틀지 않은 구간 | 13개 구간 최대 0.0004 | 10개 구간 최대 0.0002 |

- 소리를 튼 구간에서 감지된 개 짖음 3/4(시험 1)와 2/2(시험 2). 놓친 하나는 원본 점수도 0.299로 약했던 클립이다.
- 소리 없는 구간 23개와 빗소리에서 오탐은 없었다.
- 사건 영상: 감지된 구간마다 `event_video=ready`. 시험 2에서 내려받은 영상은 **H.264 + AAC, 35초, 약 8.9 MB**이고 1초 지점의 프레임은 실제 웹캠 화면이었다(평균 밝기 145). 두 번의 짖음(15초 간격)이 앞뒤 5초 패딩이 겹쳐 하나의 영상으로 합쳐졌다(설계대로).
- 외출 종료 상태 `stopped`. 시험 뒤 두 외출의 원본 음원·영상을 모두 삭제했고(`originals/videos still available: 0`) 관찰 수치만 남았다.

## 한계

- 재생 소리를 되녹음한 것이라 실제 짖음의 거리·반사·잡음과 다르다. 반대로 최대 음량으로 키워 튼 것이라 유리한 조건이다.
- 개선 사항을 끈 설정에서 잡음 바닥이 높다. 시연 때 노트북 스피커로 소리를 내려면 이 설정이 필요하고, 휴대폰 등 다른 기기로 틀면 설정과 무관하다.
- 짧거나 약한 짖음은 놓친다(dog_C). 독립 자료로 재현율·오탐률을 측정하는 일은 남아 있다.
- 시험은 한 노트북, 한 방에서 한 번씩만 했다.
- 시험 중 방에는 **배경 음악이 틀어져 있었다**(사용자가 알바 중이라고 알려 줌, 크기는 측정하지 않음). 배경 음악이 있는데도 소리 없는 구간의 점수가 0.0004 이하였던 것은 음악에 대한 오탐이 없었다는 뜻이지만, 반대로 개 짖음의 점수가 조용한 방보다 낮아졌을 수 있다. 조건이 통제되지 않았으므로 점수의 절대값을 그대로 비교하지 않는다.
- **시연 영상은 사용자의 실제 강아지로 찍을 예정이다.** 이 시험은 그 대용이며, 실제 강아지의 거리·방향·짧은 짖음·방 소음에서의 감지는 확인하지 않았다. 촬영 전에 실제 강아지로 예행연습(점수 확인, 마이크 위치, 개선 사항 설정)을 한 번 해 보는 것이 좋다. 실제 소리는 스피커 재생과 달리 에코 제거와 무관하므로 개선 사항을 켠 상태가 더 나을 수도 있어 두 설정을 비교해 본다.
