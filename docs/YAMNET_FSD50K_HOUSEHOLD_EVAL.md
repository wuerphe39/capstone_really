# YAMNet Bark 감지기 — 가정 소음·짖음 평가 (FSD50K eval, 2026-10-23)

[ESC-50 평가](YAMNET_ESC50_EVAL.md)에 없던 **말소리·초인종·노크·전화·알람·음악·울음** 같은 가정 소음과, 길이가 다른 짖음 클립을 FSD50K **eval**(공식 전수 라벨) 680개로 평가했다. 임계값은 이전에 정한 운영값 **0.05 그대로**이며 이 결과로 바꾸지 않는다. 한 클립은 5초 창 중 가장 높은 점수가 0.05 이상이면 "짖음 후보"로 본다. 요약: [docs/evidence/yamnet_fsd50k_household.json](evidence/yamnet_fsd50k_household.json).

```powershell
.\.venv\Scripts\python.exe -m scripts.prepare_fsd50k_household     # 클립 선택·내려받기(범위 요청, 약 0.6GB, Git 제외)
.\.venv\Scripts\python.exe -m scripts.evaluate_yamnet_fsd50k_household   # YAMNet 서비스(8030) 필요
```

## 자료와 선택 규칙 (점수를 보기 전에 고정)

- 양성: CC0/CC-BY 라이선스이고 `Bark` 라벨이 붙은 클립 전부(이전 평가에 쓴 클립과 ESC-50 출처 ID는 제외하고 12MB 이하): **49개**.
- 음성: 말소리 80, 노크 60, 전화 60, 고양이 60, 음악 60, 다른 동물 60, 벨소리 37, 초인종 26, 울음 28, 웃음 40, 알람 40, 종소리 40, 문 소리 40 = **631개**. 클립 해시 순서로 그룹별 상한까지 골랐다. `Dog`·`Bark` 라벨이 붙은 클립은 음성이 될 수 없다.
- 클립 길이는 0.3~30초(긴 클립은 5초 창 여러 개). 오탐은 클립 단위와 창 단위로 모두 센다.
- 한계: 이전에 평가한 클립 120개의 ID만 제외했다. 다른 이전 실험에서 본 클립이 섞였는지는 확인하지 못했다. FSD50K도 Freesound 기반이라 AudioSet과 출처가 다르지만 겹침이 없다고 보장하지는 못한다.

## 결과 (임계값 0.05)

| | 값 | 95% 신뢰구간 |
|---|---:|---:|
| 짖음 감지 | **40 / 49** (재현율 0.82) | 0.69 ~ 0.90 |
| 음성 클립 오탐 | **9 / 631** (1.4%) | 0.8% ~ 2.7% |
| 음성 창 오탐 | 9 / 1,590 (0.6%) | 0.3% ~ 1.1% |

### 가정 소음 그룹별 오탐 (클립 단위)

| 그룹 | 오탐 / 클립 | 그룹 | 오탐 / 클립 |
|---|---:|---|---:|
| 초인종 | 0 / 26 | 음악(TV·라디오 대용) | 0 / 60 |
| 노크 | 0 / 60 | 알람 | 0 / 40 |
| 전화 | 0 / 60 | 종소리 | 0 / 40 |
| 벨소리 | 0 / 37 | 문 소리 | 0 / 40 |
| **말소리** | **1 / 80** | 다른 동물(고양이 제외) | 0 / 60 |
| 웃음 | 1 / 40 | **고양이** | **3 / 60** (5%) |
| **울음** | **4 / 28** (14%) | | |

- 사람 말소리, 초인종, 노크, 전화, 알람, 음악에서는 오탐이 거의 없다. 방문·TV 상황에서 짖음으로 오인할 위험은 낮게 나왔다.
- 약한 곳은 **아기·사람 울음**(4/28), **고양이**(3/60)다. 앞의 ESC-50에서도 수탉·돼지·고양이가 약했다. 소리가 개 짖음과 음색이 닮은 동물·울음 계열이다.

### 놓친 짖음 9개

- 9개 모두 **13~28초짜리 긴 클립**이고 점수가 0.04 이하(대부분 0.001 이하)였다. 클립 전체에는 짖음 라벨이 있지만 짖음이 아주 작거나 짧게 섞여 있는 녹음으로 보이며, 5초 창 어디에서도 점수가 오르지 않았다. 길이 3초 이상 클립의 재현율은 34/43(0.79)이다.
- **3초 미만의 짧은 클립은 6개(1초 미만 1개, 1~3초 5개)뿐이고 6개 모두 감지했다.** 표본이 너무 작아(신뢰구간이 넓음) "짧은 짖음에 강하다"고 말할 수 없다. 짧은 짖음 재현율은 여전히 AudioSet 구간 평가([파트 47](47_AudioSet_시간구간_짖음_평가.md): 1초 미만 23창 중 12창 놓침)가 더 많은 정보를 준다.

## 해석

- ESC-50(40/40, 오탐 1.7%)과 합치면 운영 임계값 0.05는 **또렷한 짖음은 놓치지 않고, 사람·가전·악기 소리에는 거의 반응하지 않는** 거름망이다. 약점은 (1) 큰 소리 속의 아주 작은 짖음, (2) 울음·고양이·수탉·돼지 같은 비슷한 음색, (3) 1초 미만 짖음(AudioSet 평가)이다.
- 이 평가의 음성 클립은 대부분 단일 소리 사건이라 실제 집의 섞인 소음과 다르다. TV에서 나오는 **개 짖는 소리**는 실제 짖음과 같이 감지될 것이다(구분 불가).
- 실제 강아지와 방 환경에서의 결과는 아직 없다(시연 전 예행연습 필요).
