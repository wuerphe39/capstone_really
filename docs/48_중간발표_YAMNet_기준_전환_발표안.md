# 중간발표 수정안 — 음성 LSTM 대신 YAMNet을 기준 모델로

작성 기준: 2026-10-12. 발표: 2026-10-13. 기존 슬라이드 `docs/presentation/PetMind_3주차발표자료.pptx`(23장)와 [docs/45](45_YAMNet_임베딩_LSTM_비교.md)~[47](47_AudioSet_시간구간_짖음_평가.md)의 수치만 사용했다. 새로 측정한 값은 없다.

## 0. 발표에서 말할 결론 (한 문장)

> 짖음 후보 감지를 직접 학습한 LSTM으로 개선하려 했지만, 학습 없이 쓰는 사전학습 YAMNet 단독이 같은 평가에서 더 높은 점수를 냈다. 그래서 YAMNet을 기준 모델로 삼고, 적용은 10/19~10/23에 한다.

**"이미 LSTM을 뺐다"고 말하지 않는다.** 웹 서비스의 운영 모델은 아직 기존 LSTM이다. 전환은 결정 사항이고 구현은 계획이다. 슬라이드 6·19도 같은 입장이다("YAMNet은 별도 실험이며 아직 미적용").

## 1. 핵심 근거 (이 표 하나로 설명)

같은 평가 음원 182개(짖음 42, 기타 140). 이미 확인한 개발용 비교 자료이며 독립 테스트가 아니다.

| 모델 | 정밀도 | 재현율 | F1 | 놓침 |
|---|---:|---:|---:|---:|
| 기존 log-mel LSTM (운영, 임계값 0.9) | 0.857 | 0.286 | 0.429 | 30 |
| **YAMNet 단독 (학습 없음)** | 0.935 | 0.690 | **0.795** | 13 |
| YAMNet 특징 → LSTM | 0.966 | 0.667 | 0.789 | 14 |
| AudioSet 추가 학습 LSTM (3회) | 0.80~0.94 | 0.71~0.76 | 0.78~0.81 | 10~12 |

설명 순서:
1. 기존 LSTM은 짖음 42개 중 30개를 놓친다(재현율 28.6%).
2. 학습 없이 YAMNet 점수만 써도 재현율이 69%로 오른다.
3. YAMNet 위에 LSTM을 얹거나 데이터를 더 학습시켜도 **안정적인 개선이 없다.** 시드 3회의 결과가 서로 달랐고(0.780~0.811), 오탐이 늘어나는 경우도 있었다.
4. 별도 AudioSet 106개 구간 평가에서도 YAMNet 단독 F1 0.816이 기존 임베딩 LSTM 0.674, 추가 학습 후보 0.720~0.778보다 높았다.
5. 따라서 데이터를 더 모으기 어려운 현재 조건에서는 학습이 필요 없는 YAMNet을 기준으로 삼는 것이 합리적이다.

## 3. 발표 대본 (음성 모델 부분, 약 1분 30초)

> 교수님께서 소리를 어떻게 분석하는지 설명이 부족하다고 하셨습니다. 저희는 두 가지를 비교했습니다.
>
> 첫째는 직접 학습한 LSTM입니다. 소리를 5초씩 나눠 시간에 따른 변화를 읽습니다. 그런데 공개 음원 182개 평가에서 짖음 42개 중 30개를 놓쳤습니다. 재현율이 28.6%입니다.
>
> 둘째는 구글이 이미 학습해 둔 YAMNet입니다. 저희가 따로 학습하지 않고 짖음 점수만 사용했는데도 재현율이 69%, F1은 0.43에서 0.80으로 올랐습니다.
>
> 그러면 YAMNet에 LSTM을 더 붙이거나 데이터를 추가하면 더 좋아질까요? 세 번 다시 학습해 봤지만 결과가 매번 달라서 안정적인 개선이라고 말할 수 없었습니다. 그래서 학습이 필요 없는 YAMNet을 기준 모델로 삼고, 10월 셋째 주에 웹 서비스에 적용할 계획입니다.
>
> 한계도 있습니다. 이 수치는 이미 확인한 공개 음원으로 낸 값이어서 실제 가정에서의 정확도가 아니고, 1초 미만의 짧은 짖음은 아직 많이 놓칩니다. 그래서 다음 단계는 놓친 원본을 직접 들어 보고 가정 소음을 포함한 독립 평가 자료를 확보하는 것입니다.

## 4. 예상 질문과 답변

**Q. LSTM을 왜 뺐나? 교수님은 시계열 모델이 필요하다고 하셨다.**
A. 영상 동작 판단에는 시계열이 필요하다는 지적이 맞아 영상 LSTM을 구현해 봤다. 합성 데이터에서는 100%였지만 실제 공개 영상에서는 이동 감지 재현율이 4/9로 44.4%였고 개선 버전도 같았다([docs/25](25_실제데이터_성능비교.md)). 근거 없이 쓰면 오히려 잘못된 판단을 만들 수 있어 영상 동작 판단은 범위에서 제외했다. 소리는 YAMNet이 이미 시간 순서의 특징을 사용한다. 결합 LSTM은 시간 순서에 반응한다는 근거(순서를 뒤집으면 F1 0.789→0.747)는 있었지만 YAMNet 단독을 넘지 못했다.

**Q. YAMNet 단독이 가장 좋다는 건 평가 자료가 겹쳐서 아닌가?**
A. 그 가능성을 인정한다. YAMNet은 AudioSet으로 사전학습됐고 AudioSet 평가는 독립 평가가 아니다. 182개 평가는 이미 여러 번 확인한 개발용 자료이고, 평가 음원이 적다(짖음 42개). 그래서 "가정 환경 정확도"라고 주장하지 않으며, 가정 소음과 사람이 단 정답으로 독립 평가하는 것을 다음 과제로 두었다.

**Q. 주변 소음이나 다른 소리는 어떻게 구분하나?**
A. 음원 단위로는 AudioSet 53개 중 비짖음 15개에서 오탐이 0개였다. 하지만 5초 구간 단위로는 오탐이 4창 있었다. 생활 소음별 평가는 아직 부족하다. 비짖음 소리(초인종·노크·TV 등)를 포함한 평가 자료를 모으는 것이 다음 단계다.

**Q. 짧은 짖음은?**
A. 1초 미만 짖음 창 23개 중 12개를 놓쳤다. 임계값을 낮추면 오탐이 늘어(F1 0.792→0.778) 단순 조정은 유리하지 않았다. 약 1초 단위 특징으로 학습한 LSTM은 짧은 짖음을 한 창 더 찾았지만 오탐이 크게 늘어 채택하지 않았다. 원본 청취 후 정답을 검수하는 것이 다음 단계다.

**Q. 기본 모델 교체는 언제?**
A. 10/19~10/23이다. 현재 시연은 기존 운영 모델로 진행한다.

## 5. 말하지 말아야 할 것

- "LSTM을 제거했다 / YAMNet으로 교체했다" (아직 아님)
- "정확도 80%" 또는 "실제 환경에서 잘 잡는다" (공개 음원 개발 평가일 뿐)
- README의 28.3%(`Dog` 라벨 기준)와 이번 28.6%(`Bark` 라벨 기준)를 같은 점수처럼 비교
- 감정·불안·질환을 소리로 판단한다는 표현
- 영상 LSTM 4/9(44.4%)를 숨기는 것. 질문받으면 한계로 솔직히 답한다
