# 시연 영상 촬영 계획

기준일: 2026-10-26. 사용자 본인의 강아지로 촬영한다. 이 문서는 계획과 점검표이며, 아래 "아직 확인하지 않은 것"은 촬영 전 예행연습에서 확인한다.

## 결정한 것

- **설명은 Gemini로 한다.** 외부 LLM이 과거 기록을 근거로 설명하는 단계가 블록도의 핵심이므로 `-Gemini`로 켠다. 보내는 것은 기록에서 뽑은 문장뿐이고 음원·영상은 보내지 않는다(`docs/GEMINI_REAL_CALL_CHECK.md`). 무료 구간 입력은 Google 제품 개선에 쓰일 수 있으므로 영상에서 이 사실과 "전송 내용은 기록에서 뽑은 문장"임을 함께 밝힌다.
- **카메라는 음성 감지 창 전후의 장면 확인용이다.** 영상으로 행동을 자동 판단하지 않는다고 영상에서 말한다.
- **음악은 승인한 뒤에만 재생된다.** `-Speaker`로 켜면 이 PC 스피커에서 실제로 재생되고(임시 합성곡으로 확인함), 켜지 않으면 가상 실행이다. 영상에서 어느 쪽인지 밝힌다.

## 촬영용 실행

```powershell
.\scripts\start_demo.cmd -Gemini -Lan -Capture
```

시작 때 출력되는 Tailscale 주소(`100.x`)를 폰에서 연다. 키는 `artifacts/demo/lan-key.txt`에 있으며 화면에 나오면 안 된다(주소창이 찍히지 않게 하거나 편집에서 가린다).

- [ ] 촬영에 쓰지 않을 알림·개인 정보가 화면에 뜨지 않게 방해 금지 모드.

## 예행연습 (실제 강아지)

스피커로 튼 소리 시험은 대체 시험이었다. 실제 강아지가 떨어진 곳에서 짖는 소리와 방 소음, 짧은 짖음은 아직 확인하지 않았다.

1. 같은 방에서 30~60초 수집하고 짖음 후보의 점수를 본다(기준 0.05).
2. 마이크 위치와 거리를 바꿔 점수를 비교한다. 마이크 배열의 "오디오 개선" 기능은 스피커 시험 때문에 꺼 두었으므로, 실제 강아지에서는 꺼진 상태가 맞는지 비교한다.
3. 강아지가 짖지 않는 날의 대비: 스피커로 튼 소리로 대신하되 영상에서 그렇게 밝힌다.

## 장면 구성 (약 3분)

| # | 장면 | 화면 | 말할 것 |
|---|---|---|---|
| 1 | 소개 | 블록도 애니메이션 | 외출 중 강아지 소리를 기록하고 보호자가 확인하는 시스템 |
| 2 | 외출 시작 | PC 브라우저 | 자동 관찰로 외출을 시작, 마이크·웹캠 수집 시작 |
| 3 | 집 밖에서 보기 | 폰(모바일 데이터), 카메라 화면 | Tailscale VPN으로 접속, 공개 인터넷에는 열지 않음 |
| 4 | 짖음 감지 | 폰, 순간 목록 | 후보가 뜨고 원본 소리와 전후 영상을 재생, 의견 저장 |
| 5 | 귀가 설명 | 귀가 요약, 근거 ID | 과거 기록을 근거로 Gemini가 설명, 근거 ID 표시 |
| 6 | 음악 | 승인 화면, 스피커 소리 | 보호자가 승인해야 재생된다(-Speaker). 곡은 CC BY라 표기 필요 |
| 7 | 한계 | 자막 | 아래 "밝힐 한계" |

## 밝힐 한계

- 모델 점수는 "개 짖음 소리 후보"이며 감정·질환·원인을 판정하지 않는다.
- 실제 강아지 환경의 정확도는 검증하지 않았다(공개 음원 평가: 짖음 ESC-50 40/40, FSD50K 40/49 감지, 짧고 약한 짖음은 놓침).
- 느린 모바일 망(3G급)에서는 카메라 화면이 초당 7~14장으로 끊긴다. 집 와이파이에서는 부드럽다.
- PC 스피커 재생은 임시 합성곡으로만 확인했고 레게·소프트록 곡으로는 시험하지 않았다. GPIO 같은 별도 장치는 연결하지 않았다.
- Gemini 설명은 합성·공개 음원 자료로 검증했고 외부 사용자 정확도는 검증하지 않았다.

## 아직 확인하지 않은 것

- 실제 강아지 소리 감지(예행연습에서 확인)
- 노트북 웹캠·마이크의 장시간 운용
- 실제 강아지 기록으로 Gemini 설명을 만든 결과(합성·공개 자료로만 확인)
- 폰에서 의견 저장(보류, 촬영 전에 한 번 시험)

## 촬영 뒤

- 시험·촬영 중 녹음한 원본 소리·영상 중 영상에 쓰지 않을 것은 삭제한다(화면의 원본 삭제 기능).
- 촬영한 영상 파일, DB, 원본 소리는 Git에 넣지 않는다.
